# KiCad

Place each design in its own subfolder. Include the `.kicad_pro`, `.kicad_sch`, and `.kicad_pcb` files that exist, plus required custom symbols, footprints, and project library tables.

Record the KiCad version and export a PDF schematic for review. Local preferences, locks, and automatic backup folders are ignored by Git.
