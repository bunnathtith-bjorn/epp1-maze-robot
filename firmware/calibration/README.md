# Calibration

The calibration sketch is a placeholder. No constants or measured values have been supplied.

Keep raw readings in [data](data/README.md). For each calibration record:
- Sensor/component and port.
- Date, person, firmware commit, and hardware revision.
- Reference values and units.
- Environment and battery conditions where relevant.
- Raw readings, calculation method, and derived parameters.
- Validation on separate measurements.
- Where the parameters are used in the main firmware.

Do not treat sample values as measured robot parameters.
