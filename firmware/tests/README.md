# Component tests

Each folder is an independent Arduino sketch. The starter sketches contain no test logic.

Before testing, record the hardware/port mapping, expected behaviour, and pass criteria. For a first motor test, support the robot so the wheels can rotate without it driving off.

Suggested tests to implement:
- Motor direction and controlled stopping.
- Individual sensor raw readings and repeatability.
- Motion distance and turn repeatability after calibration.

Use [TEST-LOG.md](TEST-LOG.md) to distinguish compilation from actual hardware results.
